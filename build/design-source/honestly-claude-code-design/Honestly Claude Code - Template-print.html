CONCEPT
What a terminal actually is.
(it's a typewriter. that's it.)

It is a typewriter that talks to your whole computer. That is the entire idea. A black window. You type a sentence; the computer types back.

You will never break anything by opening it. You can only do something by pressing Enter. So: poke around. Look at it. Read what it says. Close it.

Through this book we'll use the terminal in three flavors — Mac, Windows, Linux. Every time we show a command, you'll get all three. Pick the tab that matches your machine. Skip the rest.

If a paragraph starts with the word "Tangent," it's a side road. Safe to skip. If a paragraph starts with "Heads up," read it twice — it's the kind of thing that bites you at 11pm.

iHeads up
The terminal does not have an "undo." It has a history. Press the ↑ arrow to see what you just typed.
📖PLAIN ENGLISH
terminal — the window. Also called "console" or "command line." Same thing.
📖PLAIN ENGLISH
prompt — the blinky bit waiting for you. Usually a $ or >.
↗ALSO HELPFUL
Picking a terminal app: ch. 03, p. 21
If you're scared: appendix B, p. 184
⤳RABBIT HOLE
The word "shell" comes from the fact it wraps the kernel. You will never need to care about this.

STEP 5 OF 9 • INSTALL
Install Claude Code.
Find your operating system. Copy one line. Paste it into the terminal. Press Enter. That's it.
pick yours, skip the rest
macOS
COPY
$ brew install claude-code
Windows
COPY
PS> winget install Anthropic.ClaudeCode
Linux
COPY
$ curl -fsSL claude.ai/code/install.sh | sh
TO EXIT THE INSTALLER: press Ctrl + C. Or just close the window. Both safe.
📖PLAIN ENGLISH
brew — Mac's app store, but typed. Free.
📖PLAIN ENGLISH
winget — Windows's version of brew. Already on your machine.
⚠HEY, READ THIS
If brew isn't installed, run the brew installer first. see p. 15

STEP 6 OF 9 • SAY HELLO
Talk to Claude for the first time.
One command. It will drop you inside Claude's interactive chat. There is a way out — we'll show it.
Mac, Windows, or Linux — paste this
COPY ONE LINE
$ claude
Terminal
REC
# claude says:
Welcome. I'm Claude. What are we working on?

> hi
Hi. Try asking me to read a file, or write a tiny script.

> make me a file called hello.txt that says hello
Done. hello.txt created. 12 bytes.

> [your cursor is here]
!HOW TO EXIT
Type /exit and press Enter.

Or, hit Ctrl+D.

You can come back any time by typing claude again.
STUCK? A blinking cursor means Claude is thinking. Wait. If it sits for 60 seconds, hit Esc to cancel.

TANGENT ⤳ SKIPPABLE

Wait — what even is
"an AI assistant"?
[ illustration:
a small librarian in a giant library, sketched ]

Think of Claude as a very fast, very patient librarian. You describe what you want. The librarian fetches it. If they bring you the wrong book, you say "no, the one about cats." They go again.

They are not psychic. They are very well-read. They will sometimes confidently make something up — like a librarian who really, really doesn't want to admit they don't know.

Your job is to check what they hand you. We'll cover that on page 41.

?NOT MAGIC
It's a giant pattern-matcher trained on text. That's it. Nothing supernatural.
?NOT THE INTERNET
By default, Claude reads only what's in front of it. No live web. No your inbox.
?NOT A PERSON
Be polite if you want, but it's not feelings, just etiquette. You're allowed to be blunt.
end of tangent —

IT BROKE ! THAT'S OK
Find the error.
Match the fix.
Read the line your terminal turned red. Find the closest match below. If nothing matches, jump to p. 184.
⚠ error · 1 of 3
command not found: claude
TRANSLATION: “who?” — your computer.
Close the terminal. Open a fresh one. Try again. Still no? Reinstall — p. 13.
⚠ error · 2 of 3
Error: invalid API key
TRANSLATION: “that key smells wrong.”
Run claude /key and paste again, carefully. No extra spaces, no quotes.
⚠ error · 3 of 3
network timeout
TRANSLATION: it's the wifi. probably.
Open a webpage. Did that load? If yes, try Claude again in 30 seconds. If no, fix wifi.
STILL STUCK? That's the entire point of chapter 12. Skip there now, no shame: p. 184.
